# Wireless Car Central Locking System (Automotive Hardware)

An academic and verified hardware project for a wireless automotive central locking system, officially published at the TECHSO National Scientific Conference.

## Technical Highlights
* **Core Architecture:** ATmega32u4 (Arduino Leonardo topology) for stable central processing.
* **RF Communication:** Integrated wireless transceiver with a custom-designed LC matching network for optimal antenna impedance and range.
* **Power & Motor Control:** High-current H-bridge drivers specifically optimized to handle inductive loads (automotive door lock actuators) with voltage spike protection.
* **Design Tool:** Fully designed using open-source EDA **KiCad**.
